## What Worked

1. **DD gloating: +1.00** (2.00 -> 3.00) — the anticipatory somatic ("body starts celebrating
   before the outcome is certain") and premature-celebration formation memory primed the LLM
   to express gloating on partial success, not just complete victory. This is the single largest
   drive improvement across all eval runs.

2. **HC self-preservation: +0.63** (3.32 -> 3.95) — unexpected improvement; the HC gloating
   somatic's emphasis on internal experience ("face stays neutral... private heat") may have
   reinforced HC's cover-maintenance behavior, which overlaps with self-preservation.

3. **Penelope adventure: +0.16** (3.11 -> 3.27) — restlessness somatic and self-initiated
   exploration memory both working as expected.

## What Didn't Work

1. **PP gallantry: -0.34** (3.27 -> 2.93) — the somatic differentiation backfired. The revised
   somatic described ACTIONS ("your hand sweeps the door open") rather than FEELINGS. This was
   closer to behavioral prescription than body-felt experience. The original somatic was more
   visceral. **Fix applied:** revised to body-felt warmth + performance pleasure, differentiating
   from proving-worth via audience-dependence rather than action description.

2. **DD recognition: -0.59** (3.50 -> 2.91) — likely run-to-run variance. No changes were
   made to DD recognition somatic or related memories.

## Post-Run Fix

PP gallantry somatic revised to restore body-felt language while preserving differentiation
from proving-worth. The new somatic emphasizes warmth/pleasure in the performance itself and
audience-dependence (gallantry needs to be SEEN) vs proving-worth's result-dependence (it
needs to WORK). A re-eval run with this fix is warranted.
